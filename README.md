## 📖 Sobre o projeto

Este portfólio foi criado para apresentar de forma organizada minha experiência como desenvolvedor, unindo **Front-End** e **Inteligência Artificial**. O site é dividido em seções que mostram quem eu sou, minhas habilidades técnicas e os projetos que já desenvolvi.

## ✨ Funcionalidades

- Design dark mode responsivo (mobile-first)
- Menu de navegação fixo com blur no scroll e menu hambúrguer no mobile
- Seção "Sobre" com estatísticas de trajetória
- Grid de habilidades organizado por categoria (Frontend, Backend, DevOps, etc.)
- Cards de projetos gerados dinamicamente a partir de um array de dados
- Links diretos para código-fonte e demos ao vivo de cada projeto
- Seção de contato com atalhos para e-mail, LinkedIn e GitHub

## 🚀 Rodando localmente

\`\`\`bash
# Clone o repositório
git clone https://github.com/Iago-Ferreira-Silva/portfolio.git

# Entre na pasta
cd portfolio

# Instale as dependências
npm install

# Rode o projeto
npm run dev
\`\`\`

O projeto vai abrir em `http://localhost:5173`.
