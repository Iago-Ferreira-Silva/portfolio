## 📖 Sobre o projeto

Este portfólio foi desenvolvido para apresentar minha trajetória como desenvolvedor, reunindo informações sobre minhas habilidades, experiências e projetos.

O projeto utiliza **React** para a construção dos componentes e **Vite** como ferramenta de desenvolvimento e build, com uma interface responsiva desenvolvida em **CSS**.

O objetivo é apresentar meus conhecimentos em **Front-End**, além de projetos relacionados a **Back-End, Cloud Computing e Inteligência Artificial**.

---

## ✨ Funcionalidades

- 🌙 Interface em Dark Mode responsiva e adaptada para dispositivos móveis
- 📱 Layout Mobile-First
- 🧭 Menu de navegação fixo
- 💨 Efeito de blur durante a navegação e rolagem
- 🍔 Menu hambúrguer para dispositivos móveis
- 👨‍💻 Seção "Sobre" com informações da trajetória
- 🛠️ Seção de habilidades organizada por categorias
- 📂 Cards de projetos gerados dinamicamente a partir de arrays de dados
- 🔗 Links diretos para os repositórios dos projetos
- 🚀 Links para demonstrações online quando disponíveis
- 📬 Seção de contato com e-mail, LinkedIn e GitHub

## 🚀 Rodando localmente

### 1. Clone o repositório

```bash
git clone https://github.com/Iago-Ferreira-Silva/portfolio.git
```

### 2. Entre na pasta do projeto

```bash
cd portfolio
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Após iniciar o servidor, acesse:

```text
http://localhost:5173
```
